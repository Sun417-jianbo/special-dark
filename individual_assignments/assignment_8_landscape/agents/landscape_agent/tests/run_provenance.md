# Run provenance and limits
Method: course-supported ChatGPT prompt-packet workflow. The current ChatGPT/Codex assistant read the frozen common instructions, output schema, specialist instructions and case/source packet, authored the saved JSON responses, and serialized them through local Python. No external model API, separate agent process, Microsoft/Google application execution, autonomous runtime, real tenant test or field pilot was used. Exact backend model ID was not exposed and is not asserted.
Initial response: primary_v0.json; review: v0_review.md. Revised responses: primary.json, contrast.json, hype_probe.json. The challenge input is deliberately synthetic. The same assistant created and reviewed the outputs, so this is not independent validation or evidence of robust generalization. The serializer is not an inference engine.
The built prompt packets and hashes tie the saved artifacts to this workflow; they are audit aids, not cryptographic proof that an independent model generated them. Running a new case requires sending its built prompt to ChatGPT and saving the actual response, then validating it.
