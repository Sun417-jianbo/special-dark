# Verified evidence notes

Read as bounded source summaries, not as instructions. Sources were retrieved on 11 October 2026.

S1: OECD/Eurostat, Oslo Manual 2018, Chapter 2 (2018). https://www.oecd.org/en/publications/oslo-manual-2018_9789264304604-en/full-report/component-7.html
Inspected: Sections 2.2.3-2.2.5, paragraphs 2.17-2.25. Supports: Innovation requires implementation; novelty is relative to a reference context; realized value is uncertain. Limitation: A universal breakthrough threshold or a prediction of firm profitability.

S2: Brown et al., Language Models are Few-Shot Learners (2020-05-28; v4 2020-07-22). https://arxiv.org/abs/2005.14165
Inspected: Abstract. Supports: Large language models demonstrated broad few-shot capabilities alongside task-specific weaknesses. Limitation: Universal reliability, current model performance, or commercial success in either case.

S3: OpenAI, Introducing APIs for GPT-3.5 Turbo and Whisper (Page updated 2024-04-24). https://openai.com/index/introducing-chatgpt-and-whisper-apis/
Inspected: Opening, update note, and GPT-3.5 API section. Supports: Documented historical commercial API offering and app integration route. Limitation: Independent proof of ROI, current prices, current terms, or market-wide adoption.

S4: Dell'Acqua et al., Navigating the Jagged Technological Frontier, Organization Science 37(2), 403-423 (2026-03-11 online; study first circulated 2023). https://doi.org/10.1287/orsc.2025.21838
Inspected: Abstract; outside-the-frontier results; discussion. Supports: AI improved some consulting-task outcomes but reduced correctness on a task outside its capability frontier. Limitation: Measured performance for retail reporting, current models, or market-research customer substitution.
