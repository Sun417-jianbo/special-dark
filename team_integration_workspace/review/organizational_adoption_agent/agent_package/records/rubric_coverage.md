# Rubric coverage and limits
Team synthesis/professional artifact (3points): four attributed candidates, retain/qualify reasoning, reusable eight-domain specialist and final record; not a pasted set of submissions.
Evidence/traceability (3): dated sources and limits, exact source hashes, canonical32/seven-core integrity, commonA/B packets/walkthroughs, eight targeted team cases/output JSON, original weak evidence, mechanical recheck and named implementation/source commits.
Professional judgment (3): accepted stage-specific choice, binding factor, proportionate owner/action/closure priorities, targeted missing evidence, distinction between maturity/fit/readiness, dissent and reopening triggers.
In-class discipline/handoff (1): shared inventory/log and final intake/handoff provided. This artifact records source contributions and actual approval replies; it does not establish a timed in-class production percentage. No grade is guaranteed.
