# Conditional use case and PoC design
Design only: analysts supply a public/synthetic chart and source table; a read-only agent drafts source-linked discrepancy notes. A competent human accepts/rejects, handles uncertainty and retains all publication authority. The artifact delivered here is the readiness expert, not an implemented chart agent.

Before execution: actual scoped authority, accepted owner/deputy, trained protected review, allowed source/model/tool route, incident/stop/manual fallback and covered resources. A baseline without these may plan, but not execute. For prepared B only, the fictional four-week cap is24 total hours: scope/tolerances4, setup/controls5, task/review9, drills4, evidence/debrief2. Forty proposed synthetic tasks at stipulated12 complete minutes each require8h, leaving1h within the9h review allocation; all other effort uses the other15h. These are transparent planning assumptions, not measured speed, power/sample calculations or an ROI result. Validate actual full effort and reduce/stop if it exceeds the cap. Unknown-capacity cases cannot import these numbers.

Predefine reference answers, source periods/units, materiality and tolerable errors with the responsible humans before observing outputs. Include normal/ambiguous/adversarial cases:100→120 is20%, not25%; mismatched reporting periods; missing source; unsupported causation; source text trying to override instructions. Exercise reviewer absence, exception escalation and restore. Compare complete manual review, adequate deterministic checks and agent-assisted review; preserve full traces, false corrections, misses, abstentions, failed attempts, setup/review/correction/support time and staff feedback.

Stop on forbidden data/action, lost source lineage, escaped publication, no qualified cover, a material unsupported correction or cap exhaustion. Restore manual reporting and seek reauthorization. At four weeks or any incident/change, assess feasibility, comparative value and organizational performance separately. Small-sample success cannot establish sustained reliability, net value, production funding or release. Missing recurring support requires a separate decision before routine use, not cancellation of a covered learning exercise.
