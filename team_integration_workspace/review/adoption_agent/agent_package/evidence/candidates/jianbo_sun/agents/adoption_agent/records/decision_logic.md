# Recommendation categories and decision logic

| Category | Meaning and evidence condition |
| --- | --- |
| ADOPT | Scoped operational implementation after comparable value/quality evidence, confirmed controls and readiness |
| BOUNDED EXPERIMENT | Controlled comparative workflow learning with limited time/resources, stop rules and rollback |
| PROOF OF CONCEPT | Fixed offline feasibility test, not proof of operational value |
| MONITOR | Track a named unresolved external signal when a proportionate local test cannot yet resolve the question |
| DEFER | Block the specified activity until a named prerequisite or essential evidence gap is resolved |
| REJECT FOR PRESENT | Decline this use when mismatch, consequences or a superior alternative dominates; state reopening conditions |

Authority order: define the use and alternatives; test permission/control prerequisites; assess task maturity, diffusion scope, advantage, fit, reversibility, uncertainty and consequence; interpret posture; choose a scoped action; specify evidence and dates that could change it. There is no weighted readiness score or automatic diffusion threshold. Planning an experiment is not approval to launch it.

Primary factor assessment:
- Maturity: useful historical language assistance; exact tool and retail task capability unverified.
- Diffusion: broad U.S. worker use; retail reporting peer prevalence unknown.
- Relative advantage: local net effort and cost benefit unknown after review/correction.
- Fit: narratives based on verified aggregates have a checkable reference; causal explanations require caution.
- Alternatives: manual templates and deterministic BI summaries, including staying with the current workflow.
- Reversibility: high for quarantined shadow outputs with manual process maintained; lower once managers rely on automated reports.
- Uncertainty: current model behavior, costs, ordinary-user performance and readiness.
- Consequences: erroneous sales narratives could distort inventory decisions if quarantine fails.
- Posture: moderate permits staged learning; conservative prefers archived feasibility first; neither removes control gates.

Same-assistant perspective exercise (not independent agents or stakeholders):
Advocate: waiting for complete market adoption could forfeit inexpensive learning; verified tables make a reversible comparison plausible.
Risk officer: prose can sound convincing while wrong; reported drafting speed excludes costly review; the organization cannot assume staffing or data permissions.
Synthesis: conditionally prepare a shadow comparison, with no launch before the named prerequisites. Reject both automatic rollout from FOMO and indefinite waiting without a decision trigger.
