# Recommendation categories and decision logic

Choose one principal action for the exact decision scope, with current status and subordinate future transitions explicit.

| Category | Meaning and gate |
|---|---|
| ADOPT_IMPLEMENT | Controlled operational use only with representative advantage, qualified controls, accountable approval, resources and acceptable residual risk. |
| BOUNDED_EXPERIMENT | Approved reversible nonoperational value comparison; technical pathway sufficiently plausible; no rollout implication. |
| PROOF_OF_CONCEPT | Approved isolated feasibility test of reproducible source-linked operation, before claiming comparative value. |
| MONITOR | Active source watch with owner and review interval when no justified active commitment is available. |
| DEFER | Specific remediable blocker; safe interim baseline, accountable request and reassessment condition. |
| REJECT_FOR_PRESENT | Current proposal fundamentally unsuitable or unacceptable within the horizon; not a permanent ban on the technology. |

First define scope and source-supported maturity/diffusion. Next check permission, authority and failure consequences. A missing essential gate blocks that action regardless of posture. Evaluate incremental advantage over manual and deterministic alternatives, fit, reversibility, total effort and opportunity cost of waiting. Choose the least-committing informative action justified by authorized scope and evidence. Unproved feasibility points to a POC; comparative value uncertainty after feasible operation points to an experiment; production requires a separate review.

No risk appetite changes general technology facts. More aggressive posture can accelerate requests and willingness to fund authorized learning while keeping current blocked execution deferred. A category need not change if the same permission blocker binds. Novelty, 16 percent curves, vendor useful messaging and sunk expenditure cannot establish readiness; future exit costs and delay opportunity costs still matter.

Before a proposed study, owners must confirm model/data scope, representative tasks, resource cap, materiality, error tolerances and review authority. Record material misses, false corrections, source traces, abstentions, failed attempts and full setup/review/correction/support effort. Proposed stop criteria: any permission breach or uncontrolled publication stops work; a high-severity unsupported correction pauses for diagnosis. All accepted corrections should trace to the source table. Numeric tolerances and sample breadth are to be approved, not fabricated. A small sample with zero errors cannot certify production safety.

After four weeks (a proposed planning window), technical success can support requesting a value experiment. Sustained comparator advantage, qualified controls and approvals may support separately reviewed staged implementation. Otherwise revise, monitor, defer or reject according to the actual cause. Organizational staffing, training, budget, process absorption and implementation governance are handed to the Organizational Adoption Agent and authorized humans.
