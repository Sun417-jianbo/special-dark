# Rubric coverage

The three 3-point criteria are supported by one synthesized agent and report, candidate comparison, a source-to-claim register, preserved failures, five-factor reasoning, dissent, controlled contrasts and explicit Adoption boundaries. No grade is promised.

The 1-point In-Class Project Discipline and Handoff criterion concerns actual workshop conduct and updated shared records. This package records artifact contributions and handoff work, without asserting a classroom percentage. The rubric's 36-hour finalization window and the generic one-day posting instruction differ; follow the live course deadline. Team acceptance remains required before release as an approved version.
