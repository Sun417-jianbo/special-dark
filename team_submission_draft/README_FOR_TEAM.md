# Team Workshop 2 Submission Draft

This folder is a submission-ready structure for Team Workshop 2. The substantive standard, shared workspace, and one completed workflow-evidence package are already included. Before submission, the team must replace every bracketed field and confirm that the proposed decisions reflect the discussion held during the workshop.

## Complete before submission

1. Enter the team name, section, date, and member names in `Team_Agent_Design_and_Integration_Standard.docx`.
2. Confirm or revise the decision in `team_workspace/decision_log.md`; add any dissent or unresolved issue raised by a member.
3. Add every member's agent to `team_workspace/team_agent_inventory.md` and copy each agent's evidence into `supporting_evidence/`.
4. Record actual work performed by each member in `team_workspace/version_contribution_record.md`.
5. Run the agreed common tests for each candidate agent and record failures, revisions, and integration issues.
6. Replace `[Instructor confirmation needed]` after confirming the exact submission location and whether the team submits one ZIP, selected files, or both.
