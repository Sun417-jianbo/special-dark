# Team Agent Workspace

This workspace records how the team compares, accepts, integrates, and hands off specialist agents. The 1–2 page standard is the governing document. Files in this folder provide the evidence needed to apply that standard consistently.

## Working order

1. Register each candidate agent in `team_agent_inventory.md`.
2. Record source materials and verification methods in `evidence_source_register.md`.
3. Run the common comparison procedure and preserve outputs in `evidence/`.
4. Log material failures and revisions in `test_failure_log.md`.
5. Record compatibility problems in `integration_issue_log.md`.
6. Approve, revise, or retire the agent in `decision_log.md`.
7. Attribute each material change in `version_contribution_record.md`.
8. Summarize reusable assets and unresolved risks in `final_project_handoff.md`.

## Frozen boundary

The files under the scaffold's `core/` directory define the shared input contract, output contract, and common instructions. Candidate agents may change their specialist instructions, cases, assets, responses, and records. A core change requires an explicit team decision, a version note, and retesting of every accepted agent.
